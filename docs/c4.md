# C4 Model Tables for Campus Card System

## Context Table
| Name | Description | Type |
| ---- | ----------- | ---- |
| Student | Students use the WeChat mini-program to recharge campus cards and check balances | Person |
| Campus Administrator | Administrators manage campus card information and handle lost-card reports | Person |
| Campus Card System | The core system that handles card payment, recharge and user management | Software System |
| Card Reader Terminal | Hardware terminal for students to swipe cards for consumption | External Software System |

## Container Table
| Name | Description | Technology |
| ---- | ----------- | ---------- |
| WeChat Mini-Program | Client for students to recharge and query balance | Mini-program Framework |
| Campus Card Backend Service | Core backend logic for payment, recharge and card management | Java SpringBoot |
| Database Server | Store student data, card information and transaction records | MySQL |

## Component Table
| Name | Description | Technology |
| ---- | ----------- | ---------- |
| Recharge Adapter | Receive recharge requests from WeChat mini-program | Spring Boot Component |
| Card & User Manager | Manage student information, card data and lost-card applications | Spring Boot Component |
| Card Transaction Handler | Process swipe-card consumption records sent from card terminals | Spring Boot Component |
